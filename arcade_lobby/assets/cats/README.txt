Optional cat sounds (see cat_voice.py).
By default every meow is synthesised in code, so nothing ships here.
To use real recordings, add your own original or CC0 files named after a kind:
  meow.ogg   mew.ogg   mrrp.ogg   nya.ogg   prrr.ogg      (.wav also works)
A file replaces the synth for that kind, for every cat (at its recorded pitch).
